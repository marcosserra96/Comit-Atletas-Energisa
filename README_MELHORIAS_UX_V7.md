# Melhorias UX V7

Ajustes finais desta versão:

- Refinado o alinhamento do formulário "Modelo da ficha do atleta".
- Normalizada a altura dos campos, checkbox e botão "Adicionar campo".
- Adicionadas animações sutis de entrada em cards e itens configuráveis.
- Refinado o alinhamento dos cards do extrato por lançamento.
- Ajustada a exportação do Report Oficial para evitar cortes no meio dos blocos.
- O PDF agora insere espaçadores antes de seções que cairiam quebradas entre páginas.
- O gerador também exporta página por página, em vez de deslocar uma única imagem gigante.

Validação recomendada:

1. Abrir Ajustes > Modelo da ficha do atleta e testar o alinhamento em tela cheia e menor.
2. Abrir Lançamentos > Extrato e verificar os cards.
3. Gerar o Report Oficial e conferir se nenhum bloco foi cortado no meio.
4. Testar em tema claro e escuro.
