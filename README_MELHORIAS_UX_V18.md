# Melhorias UX V18

Esta versão faz uma revisão fina de contenção visual:

- evita textos, botões, inputs e selects saindo de cards, modais e containers;
- força `box-sizing: border-box` global;
- padroniza comportamento de quebra de texto em cards e modais;
- melhora rodapés de modais para que botões não escapem;
- mantém o modal de edição de lançamento com tamanho estável;
- adiciona rolagem interna em áreas grandes de modais;
- melhora responsividade de grids e formulários;
- mantém abas roláveis horizontalmente em telas menores.

Não houve mudança de regra de negócio.
