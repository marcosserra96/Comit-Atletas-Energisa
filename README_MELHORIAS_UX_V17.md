# Melhorias UX V17

Esta versão faz uma revisão fina de UI/UX, sem alterar regras de negócio.

## Ajustes principais

- Padronização de altura de inputs, selects, textareas e botões.
- Melhor alinhamento entre campos dentro da mesma tela.
- Modal de edição de lançamento com tamanho estável ao alternar abas.
- Conteúdo das abas passa a rolar internamente, sem redimensionar todo o modal.
- Rodapé do modal de edição permanece proporcional e previsível.
- Refinamento de animações sutis em cards, botões e abas.
- Ajustes de responsividade para ficha e modal de lote.

## Arquivos ajustados

- `css/admin.css`
- `js/modules/pontuacao.js`

## Validação

Validar principalmente:

1. Ficha do atleta em abas.
2. Modal de edição do lançamento.
3. Campos em Ajustes > Modelo da ficha.
4. Tela de lançamento.
5. Extrato por lançamento.
